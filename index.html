Setup & Documentation

What is OmniSearch AI?

A unified search dashboard. Enter one query and explore four providers — YouTube, ChatGPT, Google, and Meta AI — on a single page.

Run locally

  1. Save this file as index.html.
  2. Open it in a browser, or serve it: python3 -m http.server 8000
  3. Visit http://localhost:8000

Connect live APIs (optional)

Replace the generateMock* functions with fetch calls to a server-side proxy. Endpoints:

  • /api/youtube?q= → items: title, channel, views, duration
  • /api/chatgpt?q= → { answer: string }
  • /api/google?q= → items: title, url, snippet
  • /api/meta?q= → { answer: string }

Always proxy server-side to avoid CORS and protect API keys.

Privacy

Theme and search history are stored only in your browser's localStorage. No account, no tracking, no external API calls in demo mode.
